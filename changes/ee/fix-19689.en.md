Fixed partial configuration updates through `PUT /api/v5/configs?mode=merge`. An omitted setting could fail the request or overwrite the stored value:

- The request failed with a `converter_crashed` error when it omitted `log.file`, for example in a merge of only `log { console { ... } }`. The same happened for any partial merge of the `dashboard` root, for the `server` of an InfluxDB, Elasticsearch or Datalayers connector, and for the `key` of a message transformation operation.
- An omitted TLS `ciphers` setting reset the configured cipher list to the default.
- A partial merge of the `listeners` root brought back the deleted default listeners.
