Fixed an issue where some authenticated callers could not read the API documentation endpoints (`/api-docs/swagger.json`, `/api-spec.json`, `/api-spec.md`, `/api-spec.html` and `/api-spec/:tag`).

- Dashboard users and API keys with an explicit scope list can now read these endpoints, whatever scopes they hold.
- Dashboard users and API keys with the viewer role or a namespaced administrator role can now read these endpoints.

Requests without credentials still get HTTP 401.
