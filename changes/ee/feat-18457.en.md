HTTP authentication can now signal a bad-credentials failure. When the authentication server returns `"result": "deny_bad_credentials"`, EMQX replies to the client with CONNACK reason code 0x86 (Bad User Name or Password). MQTT 3.1.1 clients receive return code 4. The existing `"result": "deny"` value is unchanged and still produces 0x87 (Not Authorized; return code 5 for MQTT 3.1.1 clients).
