Despite having the `resource_opts.health_check_timeout`, some Connectors/Actions/Sources did not actually use that value for timing out health checks.  This has been fixed.

The affected integrations were:

- Cassandra Connector
- DynamoDB Connector
- GCP PubSub Consumer Source
- IoTDB Connector (Thrift driver)
- Snowflake Aggregated Connector
- SQLServer Connector
- TDEngine Connector
- MySQL Connector
- Doris Connector
- Postgres Connector
