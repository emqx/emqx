Reduced memory allocation and CPU overhead when delivering QoS 1 and QoS 2 messages through in-memory sessions.

During rolling upgrades, inflight-message REST API pagination has two limitations:

- Older nodes reject pagination cursors with HTTP 400 if successive REST requests switch from a 6.3.3 node to an older node.
- After session takeover from a 6.3.3 node to an older node, inflight messages with the same microsecond delivery timestamp can be skipped if they span multiple pages.

MQTT message delivery is unaffected.
