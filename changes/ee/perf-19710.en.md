Topic matching no longer splits the topic into levels in these places:

- shared-subscription topic matching;
- the `topic_match` function of rule engine SQL and variform expressions;
- the route updates of cluster links.

The result is the same as before for a valid topic. The `topic_match` function takes runtime data, and a topic with a `#` level that is not the last level is not a valid topic. Such a topic now matches a filter with a trailing `#` where it did not match before. For example, `topic_match('#/a', '#')` now returns `true`.

The default `acl.conf` now compares the `dashboard` username with an equality check instead of a regular expression.
