Bumped OTP version to 28.4.1-7 and builder version to 6.2-3.

This reduces the memory used by each TLS connection: the per-connection ETS table for shared socket options is gone, and idle TLS 1.3 connections release their cipher state. A TLS handshake also no longer makes two calls to the Erlang file server to resolve an absolute `cacertfile` path, which removes a file-server backlog under a burst of TLS connections.
