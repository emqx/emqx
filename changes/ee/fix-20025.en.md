The `.deb` packages now depend on `procps`, `adduser` and `awk`.

Previously, on a host without `procps` (for example the `debian:12` container image), the `emqx` command printed `ps: command not found`, `emqx stop` returned before the node had exited, and a node started with `EMQX_NODE__NAME` set was not refused when it was already running. On a host without `adduser` (for example the `ubuntu:24.04` and `debian:13` container images), installing the package failed in the post-install script.
