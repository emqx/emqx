Made HTTP request parsing on the Dashboard, the REST API and the WebSocket listeners stricter:

- HTTP/2 requests are limited to 32 KB of decoded headers. When a request has larger headers, EMQX resets the HTTP/2 stream with the error code `ENHANCE_YOUR_CALM`. Other requests on the same connection are not affected.
- HTTP/2 header blocks sent in several frames are limited to 32 KB.
- HTTP/2 header blocks that encode an integer of more than 38 bits are rejected with a connection error.
- HTTP/1.1 requests with more than 100 header lines are rejected with status 431, also when header names repeat.
- HTTP/1.1 request bodies with a chunk size of more than 16 hex digits are rejected.
- Multipart request bodies with a part header block larger than 2048 bytes are rejected.

EMQX also applies the 32 KB limit to the headers and trailers of HTTP/2 responses it receives, for example from ExHook and ExProto gRPC servers. A gRPC call fails when the server returns larger metadata.
