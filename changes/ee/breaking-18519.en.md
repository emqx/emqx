QuasarDB Action now automatically escapes and quotes values when rendering its `INSERT` statements.  To handle timestamp values, which for QuasarDB must not be quoted, a `#nowrap` modifier has been introduced.  To use it, append `#nowrap` to the placeholder definition.  For example, rendering `${.payload.ts#nowrap}` with a `"2026-03-09T11:38:55"` value will result in `2026-03-09T11:38:55` (not wrapped in single quotes).  Without the modifier, it will be rendered as `'2026-03-09T11:38:55'`.
