Fixed `emqx start` so that it refuses to start a node that is already running.

Previously, `emqx start`, `emqx console` and `emqx foreground` checked for a running node only when the node name was set with the `EMQX_NODE__NAME` environment variable, and never when run as root from a `.deb` or `.rpm` installation. A second `emqx start` then printed that the node had started, although the new node failed to start because its ports were in use. The check now uses the node name from `emqx.conf` too.

The `emqx` command now exits with an error when the `ps` command is not installed. Before, it printed `ps: command not found` and continued without the running-node check, and `emqx stop` returned before the node had stopped.
