Fixed MQTT sources with a `clean_start = false` connector unsubscribing from the remote broker when EMQX stopped, so the remote broker queued nothing for them while the node was down. With `proto_ver = v3` or `v4`, the subscriptions now stay in the remote session. A `$share` subscription stays only when no other node in the cluster is running, for example on the last node of a cluster stopped one node at a time. When all nodes stop at the same time, each node may still see the others running and remove its `$share` subscription.
