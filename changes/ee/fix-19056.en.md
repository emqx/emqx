Fixed an error when saving the OIDC single sign-on configuration through the Dashboard or the REST API. This affects release 5.10.5.

`GET /api/v5/sso/oidc` returned `client_jwks` as `******`, and submitting that response back with `PUT /api/v5/sso/oidc` was rejected with `matched_no_union_member`. The field now keeps its structure: `none` is returned as is, and a configured JWKS returns its `type` with only the `file` value masked. Submitting the masked value back keeps the stored JWKS unchanged.
