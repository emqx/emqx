Denied a small set of names (`global`, `undefined`, `null`, `none`) from being used as a namespace identifier — neither as an admin namespace nor as a per-client `client_attrs.tns`. These names collide with internal sentinels and would produce ambiguous log lines and dashboard output. The list is configurable via `multi_tenancy.deny_namespaces` ([#18123](https://github.com/emqx/emqx/pull/18123)); set it to an empty list to disable the restriction.
