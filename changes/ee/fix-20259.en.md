In CoAP connection mode, changed how the gateway handles a message that arrives from another address or names another client ID than the connection it reaches.

- On a UDP listener, the gateway now changes the address it sends to for a client only after a request from the new address passes the client ID and token check. Until then, messages for the client keep going to its current address.
- On a UDP listener, ACK, reset and response messages are accepted only from the client's current address.
- A connection that already serves one client now refuses a request that names another client ID, also when the request carries a valid token for that client ID. To continue as another client, close the connection and connect again.
