Replicant nodes now accept core nodes of a different EMQX patch version during a rolling upgrade, as long as both versions share the same database schema version and the same `mria` version.

Before, a replicant connected only to core nodes running exactly the same `emqx` application version, so replicants lost their core nodes while the cores were being upgraded ahead of them. The health check warning `no_available_core_node_at_same_version` now reports the database schema and `mria` versions of the known core nodes.

A core node from a release older than this one is still matched by exact `emqx` application version, as that release requires.
