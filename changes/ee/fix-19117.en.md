Messages buffered by an `mqtt` action are no longer lost when the remote broker is unreachable: connection-level failures (for example `ssl_closed`, `econnrefused`, keepalive or socket timeouts and DNS errors) are now retriable, so the queries stay in the buffer until `request_ttl` expires instead of being counted as `failed` (with fallback actions configured, such a request now triggers the fallback when it expires instead of immediately).
