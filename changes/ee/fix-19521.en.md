Fixed HTTP actions discarding messages on HTTP 502 and 504 responses or temporary DNS resolution failures (`nxdomain`). These errors are now recoverable, allowing the action buffer to retry until the request TTL expires.

Fixed HTTP actions ignoring `parameters.max_retries` in synchronous and asynchronous query modes. The parameter now controls retries within each action query, independently of retries performed by the action buffer. Existing free retries for normal connection shutdown races remain unchanged.
