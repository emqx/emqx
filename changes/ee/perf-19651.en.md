Keep the per-connection stats in an atomics array owned by the connection process instead of writing them to the `emqx_channel_info` table.

Each row of the table now holds a reference to the array. The packet and message counters are incremented in place, so `GET /clients`, `GET /clients/{clientid}` and `emqx ctl clients show` report them as they happen instead of up to one stats interval late. The row is no longer rewritten after each `SUBACK` and on every stats timer tick, which removes a decompress-and-recompress of the row on each of those writes, and the counters no longer live on the heap of the connection process.

The seven `seqno_q1_*` and `seqno_q2_*` fields of a durable session, which `GET /clients` and `GET /clients/{clientid}` showed with no consumer, are removed from the response. `n_streams` stays.
