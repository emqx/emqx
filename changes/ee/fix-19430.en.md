Fixed several `emqx ctl` commands that printed their output and then exited with code 1. A shell script that runs with `set -e`, or chains commands with `&&`, stopped after these commands even though they had succeeded. These commands now exit with code 0 on success: `broker stats`, `broker metrics`, `vm`, `vm all`, `vm load`, `vm memory`, `vm process`, `vm io`, `vm ports`, `mnesia`, `topics show`, `subscriptions show`, `traces list`, `gateway-clients list`, `rebalance start` and `rebalance stop`. The audit log also recorded each successful run of these commands at `error` level. It now records them at `info` level.

`emqx ctl rebalance` and `emqx ctl a2a_registry` now exit with code 1 when the command fails.
