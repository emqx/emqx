Reduced the memory an idle MQTT connection holds.

A connection now hibernates after `mqtt.hibernate_after`, which defaults to 5 seconds without traffic. Hibernation shrinks the connection process heap to the data still in use and releases about 5 KB per connection.

Before this change, TCP and TLS connections hibernated only after `mqtt.idle_timeout`, which defaults to 15 seconds, and WebSocket connections stayed awake after they received their first packet.

Set `mqtt.hibernate_after = infinity` to keep connections awake. Raise the value when clients send data at intervals close to it, because each hibernation costs one garbage collection and the heap grows again on wake-up.
