Upgraded cowlib to 2.22.0 and updated the HTTP server (cowboy) and HTTP client (gun) to match. This changes the following for the Dashboard, the REST API and the WebSocket listeners:

- An HTTP/2 request is rejected when its decoded headers are larger than 32 KB. The server resets the stream, and the connection stays open.
- An HTTP/1.1 request with more than 100 header lines is rejected with status 431. Header lines with the same name now count separately.
- A multipart request is rejected when the headers of one part are larger than 2048 bytes.
