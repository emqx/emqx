Validate managed namespace names at creation, and keep every namespace's backup files in its own directory.

A managed namespace name may now contain only ASCII letters, digits, and the characters `.`, `-`, and `_`, with a length of 1 to 255 bytes; the names `.` and `..` are not accepted. This ensures every namespace name works correctly in URLs and on the file system. Namespaces that already exist are not affected.

Independently, backup file operations now always resolve to the namespace's own directory under the backup root. Previously, a namespace named `..` resolved to the cluster's global backup directory, so listing, downloading, or deleting backups from such a namespace operated on the global administrator's backup files.
