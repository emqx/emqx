The `emqx_maptabs` plugin now has a REST API. A mapping table can be uploaded, replaced, read back, listed, deleted and reloaded over HTTP, so it is no longer necessary to copy a file to a node and run `emqx ctl maptabs`.

The endpoints are under `/api/v5/plugin_api/emqx_maptabs/` and need an API key with the `plugin_api` scope. An upload or a delete answers success only when every running node has confirmed it. When a node does not confirm, the answer is a 503 that names the node, and the change stays stored; repeat the same request to complete it.
