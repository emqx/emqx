Hardened the `/api/v5/prometheus/topic_metrics` endpoint so that a request renders only the
topic-metric collections owned by the API caller's namespace, consistently with the other
namespace-aware Prometheus endpoints. A global administrator, viewer or API key still sees all
namespaces, or a single one named with the `ns` query parameter. A namespaced caller may name
only its own namespace; naming another one is rejected with `403`.
