Added SQL Server UPDATE templates for actions with `resource_opts.batch_size = 1`.
Templates can use rule output variables in both SET expressions and WHERE conditions.
UPDATE actions with batching enabled report a configuration error.

SQL Server actions preserve UTF-8 Unicode values, including Emoji, in Unicode-capable columns
for both INSERT and UPDATE templates.
String values containing invalid UTF-8 return a rendering error; INSERT batches containing
such values are rejected before execution.
Actions preserve line endings in string values and report errors after trigger result sets.
Value encoding preserves floating-point precision and Unicode character lists, including
non-hexadecimal strings starting with `0x`. Short encoded strings retain bounded SQL types.
Unicode data values no longer change the statement's execution context for ordinary identifiers.
