Upgraded esockd from 5.17.2 to 5.17.7. Changes visible to users:

- TCP listeners with `tcp_backend = socket` now set `tcp_options.recbuf`, `sndbuf` and `nodelay` on the listening socket, as the `gen_tcp` backend does. Previously they were applied to each accepted socket after the TCP handshake. A `recbuf` below the operating system's default receive buffer then throttled all inbound traffic on every connection of the listener, whatever the message size; with `recbuf = 4KB` a connection received about 20 KB/s. `recbuf` has no default, so listeners that do not set it were not affected. A change of these options on a running `socket` listener is now applied in place instead of restarting the listener.
- Listener shutdown counters (`emqx ctl listeners`) gained `closed_early`, for connections the peer closed or reset before a connection process was started, and `closed_forbidden`, for connections denied by the listener's access rules. Such connections were not counted before.
- Proxy protocol v2: a header with no address information no longer consumes the first bytes of the client's data, and a header with a truncated address block is rejected instead of crashing the connection.
- TCP listeners with `tcp_backend = socket` use slightly less memory per connection.
