Performance improvement for durable sessions publishing QoS2 messages.

- The persistent map backing the session state storage skips the
  storage operations that would not change anything, such as the
  deletion of a key that is known to be absent.

- Reduced the memory used by optimistic transactions on the
  durable-session data. The optimistic transaction manager can now
  track conflicts for an entire topic filter instead of the individual
  keys within it, and the persistent-map layer marks the topic filters
  of the collections it commits as dirty. Together this reduces the
  size of the in-RAM conflict index that each durable-storage shard
  process keeps for the session data.
