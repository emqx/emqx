Fixed plugin package installation so that a package can only write to the directory of the plugin name it was authorized for. Previously a package uploaded for one plugin could contain files of another installed plugin and overwrite them, and when the package was rejected the cleanup deleted that other plugin's whole directory. Packages are now unpacked into a private staging directory below the plugins install directory, every archive entry must stay below the package's own name, and the install directory is only updated with a single atomic rename: a refused package leaves no partially written plugin directory behind and can not modify another plugin's installation.
