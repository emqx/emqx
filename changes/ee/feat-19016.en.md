Added the `POST /certs/global/name/:name/trusts` API. It adds CA certificates to a managed certificate bundle and keeps the CA certificates the bundle already has. Certificates already in the bundle are skipped.

Added the `DELETE /certs/global/name/:name/trusts/:fingerprint` API. It removes one CA certificate, selected by its SHA-256 fingerprint, from a managed certificate bundle.

Uploading files to a managed certificate bundle no longer leaves a partly written file when a write fails. When writing any of the uploaded files fails, the files in the bundle stay unchanged.
