EMQX now logs a notice when a config change sets a listener bind address to a host-specific IP address (an address other than the wildcard or loopback). This gives an early signal that the config is not portable: a warning when the address works on the current node but breaks after migrating the config or a backup to another host, and an error when the address is not available on the node's network interfaces or when the cluster has more than one node. The config change itself is applied as before.
