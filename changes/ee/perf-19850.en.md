Reduced the memory an idle MQTT connection occupies.

A connection process now hibernates after half of `mqtt.idle_timeout` instead of after the full value. The full value is also the period of the statistics timer, whose arrival restarted the hibernation deadline, so an idle connection kept waking up instead of hibernating.

A hibernating connection also no longer wakes up once per `mqtt.keepalive_check_interval` to sample its receive counter. It now sets a single timer for the moment the client is late, and checks the counter when that timer fires. Keepalive timeouts are reported at the same time as before.
