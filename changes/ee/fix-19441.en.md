Fixed `emqx ctl` commands that gave wrong or missing output:

- `emqx ctl conf reload` now prints the reason, the effective configuration and the attempted configuration when it cannot apply a configuration root on the local node. A successful reload now reports the node name instead of `cluster`.
- `emqx ctl conf load --namespace <ns> --replace` now shows the configuration stored in that namespace when it cannot apply a configuration root. Before this fix, it showed the global configuration.
- `emqx ctl listeners enable` now prints `Listener not found` for a listener that does not exist.
- `emqx ctl topics show <Topic>` now prints the routes of the topic. Before this fix, it printed nothing and exited with code 1.
