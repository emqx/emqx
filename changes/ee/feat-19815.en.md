The `arrow_flight` driver in the Datalayers connector now uses `datalayers-adapter-erl` 0.1.6.

Arrow Flight TLS connections verify the Datalayers server certificate. They default to
`cacertfile = "system_default"` and `verify = verify_peer`. The `system_default` value uses the CA
bundle from `node.trusted_certs`. A PEM CA path can replace the default. The connector
rejects `verify_none`, client certificate settings, and `managed_certs`.

The default `influxdb_v1` driver keeps its existing TLS behavior.
