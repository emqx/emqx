Auto-subscribe topics now support `${client_attrs.<key>}` placeholders. A client can be automatically subscribed to topics built from the client attributes set by `mqtt.client_attrs_init`, for example `sub/${client_attrs.tenant}/${clientid}`.

Placeholder handling is also stricter now. Previously, a mistyped or unsupported placeholder was silently kept as literal text in the subscription topic. Now a topic referencing a client attribute the client does not have is skipped with a warning log, the same way `${username}` topics are skipped for clients without a username. Unknown placeholders are still kept as literal topic text, but a warning is logged when the configuration is loaded.
