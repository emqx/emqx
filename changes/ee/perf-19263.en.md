Reduced the memory each connection occupies in the client information table by about 100 bytes.

The table no longer stores values it can already reach elsewhere in the same record:

- The whole `sockinfo` map. Its `socktype`, `peername` and `sockname` fields are also under
  `conninfo`, which still carries them; its `sockstate` field is internal to the connection process
  and had no reader outside it.
- The `peerhost`, `peerport`, `peername` and `sockport` entries under `clientinfo`, whose values come
  from `conninfo.peername` and `conninfo.sockname`.

This changes the stored copy only. Hook callbacks receive the connection's own client information
rather than the table's, and that still carries every one of these fields, so authentication,
authorization and hook handlers are unaffected. REST API responses are unchanged as well.
