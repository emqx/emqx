Reduced the memory each connection occupies in the client information table by about 56 bytes.

The table no longer stores the `sockinfo` map. Three of its four fields — `socktype`, `peername` and
`sockname` — duplicated fields of the same name under `conninfo`, which still carries them. The
fourth, `sockstate`, is internal to the connection process and had no reader outside it.

Client information returned by the REST API is unchanged, and so are the arguments passed to hook
callbacks.
