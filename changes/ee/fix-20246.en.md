The HTTP authenticator and the HTTP authorizer no longer send a request when the URL path has a `.` or `..` segment after placeholder substitution, including the percent-encoded forms such as `%2e%2e`.
The HTTP authenticator then ignores the login, so the next authenticator in the chain decides; when no other authenticator accepts it, the login fails.
The HTTP authorizer denies the action, whatever the `authorization.no_match` setting is.
The same applies to such a segment in the configured URL itself. Remove it from the URL.
