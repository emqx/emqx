Handle license rejections cleanly in the STOMP, NATS, CoAP, LwM2M, OCPP,
JT/T 808, and MQTT-SN gateways. Text responses include a readable reason,
JT/T 808 returns an authentication failure, and MQTT-SN returns its
congestion code. Clients can connect again after the license limits recover.

OCPP also returns HTTP 400 with a readable reason when a connection hook
returns invalid or incomplete character data.
