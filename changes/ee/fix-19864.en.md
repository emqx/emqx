The Datalayers Arrow Flight connector now uses `datalayers-adapter-erl` 0.1.6.

When TLS is enabled, server certificate verification defaults to `verify_peer` and
`verify_none` is rejected. The connector requires an explicit PEM CA path. It accepts
environment variables in the path and resolves relative paths to absolute paths.
Client certificates, managed certificates, and disabled SNI are not supported.

The default `influxdb_v1` driver keeps its existing TLS behavior. Database selection errors
now include the database name and the adapter error.
