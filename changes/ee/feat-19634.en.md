Added optional HTTP health checks for HTTP Connectors. These checks detect HTTP failures
even when the TCP connection remains open.

Set `health_check.enable = true` and configure `health_check.path` to enable the check.
Use `health_check.method` to select GET or HEAD. The endpoint must return a complete 2xx
response within `resource_opts.health_check_timeout`. If the check fails, EMQX marks the
Connector and its Actions as disconnected and raises an alarm. They recover when the check succeeds.

The check is disabled by default.
