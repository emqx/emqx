Fixed MQTT maximum packet size enforcement to count the entire packet.

Previously, the streaming parser checked only the Remaining Length value (the variable header and payload). It did not count the one-byte packet type/flags field or the one to four bytes encoding Remaining Length. For example, a 129-byte PUBLISH with Remaining Length 127 could be accepted and routed even when CONNACK advertised a maximum packet size of 128 bytes.

The parser now enforces the limit on the total packet size, including these fixed-header bytes. Packets exactly at the limit remain accepted.

See MQTTv5 Section 2.1.4 (Remaining Length).
