Support template variables in the URL host of the HTTP authenticator and HTTP authorizer, e.g. `https://${client_attrs.tns}.auth.example.com/authn`, enabling per-tenant authentication and authorization endpoints without an external routing layer.

When the host is templated, EMQX sends each check as an individual HTTP request to the rendered host instead of going through the fixed connection pool, applying the configured TLS options (including peer verification) to that host. The new `allowed_hosts` setting must list the hostnames a templated host may render to, either as exact names or as `*.suffix` wildcard patterns; when the rendered hostname is not covered by this list, no request is made and the check fails. URLs with a literal hostname keep using the connection pool exactly as before.
