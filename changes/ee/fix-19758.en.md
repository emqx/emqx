Fixed gateway WebSocket connections when the client omits an optional subprotocol header. An empty supported list no longer causes a crash. The gateway no longer sends a subprotocol that the client did not request.

On EMQX 6.1 and later, the HTTP API preserves NATS and OCPP WebSocket defaults when the request omits these options. Explicit empty and custom values remain unchanged.

The OpenAPI documentation shows the correct WebSocket defaults for NATS and generic listeners.
