Fixed WebSocket listener handling for gateways:

- Accept connections without a `Sec-WebSocket-Protocol` header when `fail_if_no_subprotocol` is `false`, including when the configured subprotocol list is empty. Do not send an unsolicited subprotocol response header.
- Preserve the NATS and OCPP WebSocket defaults in the gateway API schema. On EMQX 6.1 and later, omitted options no longer become empty values when a gateway is configured through the API. Explicit custom and empty values remain unchanged.
- Keep NATS WebSocket defaults separate from generic listener defaults in the combined OpenAPI specification.
