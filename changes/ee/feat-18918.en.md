Added a `disconnected_connections.count` gauge for sessions whose client has disconnected but whose session expiry interval has not yet elapsed.

A persistent session is held by its connection process after the client disconnects, until the client reconnects or the session expires. Previously the only way to observe how many sessions were in that state was to subtract `live_connections.count` from `connections.count`; the number was not published anywhere.

The gauge is available on the node stats HTTP API, in the Dashboard's Metrics page, and as the Prometheus metric `emqx_disconnected_connections_count`. It is computed from the two tables already used for the `connections.count` and `live_connections.count` gauges, so it adds no per-session work to the stats tick.
