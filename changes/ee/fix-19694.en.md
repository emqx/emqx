Hardened HTTP and WebSocket handling by updating the `gun` and `cowlib` dependencies. The HTTP/1.1 and WebSocket parsers are stricter and the HTTP client applies response header and frame size limits by default, which can break integrations that communicate with legacy or non-compliant HTTP or WebSocket services; verify such integrations after upgrading.

The REST API now rejects requests with more than 100 query parameters, and the limit is documented in the generated API specification.
