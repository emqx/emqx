Reduced the memory each connection occupies in the client information table by the length of
its client identifier and username.

The table no longer stores the `clientid` and `username` entries under `conninfo` when they are
equal to the ones under `clientinfo`, which it keeps. They still appear under `conninfo` when the
CONNECT packet values differ from the ones the client ended up with, for example when the broker
assigned the client identifier.

This changes the stored copy only. Hook callbacks receive the connection's own connection
information, which still carries both fields, and REST API responses are unchanged.
