Added an MFA enrollment status to the Dashboard API, so the Dashboard can offer two-factor authentication to users who have not enabled it instead of leaving it undiscoverable.

The status is one of `complete` (enrolled and verified), `pending_enforced` (MFA is required and not complete, so the next login stops for setup), `pending_voluntary` (no MFA and nothing requires it) or `disabled` (opted out, and nothing requires the user to opt back in). It is derived from state that already exists, so no new configuration is involved, and it is returned only after the first factor has been verified: in the login response, and from `GET /api/v5/current_user`, which needs no user management permission.
