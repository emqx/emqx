Added the optional `region` field to the S3 connector and to the S3 exporter of file transfer. When it is set, requests and presigned URLs are signed with this region instead of the region inferred from the endpoint host.

When `region` is not set, the region is now correctly inferred from AWS S3 interface VPC endpoint (PrivateLink) hosts, for example `bucket.vpce-1a2b3c4d-5e6f.s3.us-west-2.vpce.amazonaws.com`. Before this change, requests to such endpoints were signed with `us-east-1`, and AWS rejected requests to endpoints in other regions.
