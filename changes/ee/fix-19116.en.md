Improved the error message when a REST API request sends data that is not text, where text is expected. An example is a certificate in DER format in a field that needs the PEM format.

EMQX now refuses the value, reports that it is not valid UTF-8 text, and gives its size. Before, the message showed the content of the value as a long list of numbers, and said that the value had the wrong type although the request did contain one.

A configuration field that accepts any value no longer stores such data. Before, it stored an internal error in place of the value.
