Enabled periodic global garbage collection by default, with an interval of 15 minutes.

Set `node.global_gc_interval` to `disabled` to turn it off. Each run walks all processes and forces a garbage collection on each process that waits. The run is spread over the first half of the interval ([#19914](https://github.com/emqx/emqx/pull/19914)), so its cost stays a small share of the node's CPU time rather than a spike.
