Removed the count of socket receive and send operations from the per-client statistics.

The per-client `recv_cnt` and `send_cnt` fields now show the number of MQTT packets received and sent, the same values as `recv_pkt` and `send_pkt`. Before, they showed the number of TCP packets. This applies to the `/clients` REST API, the `emqx ctl clients stats` CSV export, and the stored information of durable sessions. The fields are kept for compatibility.
