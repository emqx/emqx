Fixed inconsistent frame size limit enforcement in the STOMP, NATS and JT/T 808 gateways, bounded STOMP transaction usage, rejected non-positive STOMP transaction timeouts, and prevented LwM2M re-registration from reusing a session with a different client identity. The NATS gateway now limits control lines with `max_control_line` while retaining `max_payload_size` for message data and INFO.max_payload.
