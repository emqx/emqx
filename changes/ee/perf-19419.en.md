Reduced the memory each connection occupies in the client information table. The table no longer stores the connection's socket term under `conninfo.sock`. Each entry is 16 bytes smaller for a TCP connection with the `gen_tcp` backend, 32 bytes smaller with the `socket` backend, and about 128 bytes smaller for a TLS connection.

This changes the stored copy only. Hook callbacks receive the connection's own `conninfo`, which still carries `sock`. REST API responses are unchanged. Plugins that read the table directly, through `emqx_cm:get_chan_info/1,2`, `emqx_cm:lookup_client/1`, `emqx_mgmt:lookup_client/2`, `emqx_channel:info/1` or `emqx_connection:info/1`, no longer see `sock` under `conninfo`. Use `emqx_channel:info(conninfo, Channel)` in the connection process to read it.
