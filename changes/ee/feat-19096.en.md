Added the `mqtt.max_connect_packet_size` setting. It limits the size of a CONNECT packet, in addition to `mqtt.max_packet_size`. EMQX closes the connection of a client whose CONNECT packet is larger, and counts it under the listener shutdown counter `connect_packet_too_large`. The default is `1MB`, the same as the default `mqtt.max_packet_size`, so nothing changes until the setting is lowered.
