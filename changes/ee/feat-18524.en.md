Added a `service.dashboardEnabled` option to the `emqx-enterprise` Helm chart. Set it to `false` to omit the dashboard (HTTP/HTTPS) ports from the externally exposed Service, for example to keep the dashboard off a LoadBalancer that exposes the MQTT ports. The default is `true`, so existing deployments are not affected. The headless Service keeps the dashboard port for in-cluster access and Prometheus metrics scraping.
