Fixed a 5-second delay and a `shutdown_error` supervisor report when a TLS connection closed while its sender process was busy, for example on a heavily loaded node. A process sending on such a connection now gets a closed-connection error at once instead of exiting.

Fixed a memory leak in the Erlang/OTP HTTP client (`httpc`). Each asynchronous HTTP request, and each synchronous request that failed before it was sent, left about 100 bytes in the process that made the request, and the memory was freed only when that process exited. The most visible case was JWT authentication with a JWKS endpoint: the JWKS client processes grew with every key set refresh.
