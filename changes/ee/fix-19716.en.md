Updated the bundled CA trust store to the Mozilla CA set as of 2026-10-20.

The bundle moves from certifi 2.10.0 (142 certificates) to 118 certificates. Among the roots it no longer contains are
`emSign ECC Root CA - G3`, `AAA Certificate Services`, `emSign Root CA - C1`, `emSign ECC Root CA - C3`,
`SecureSign Root CA12` and `Atos TrustedRoot 2011`; it gains the roots Mozilla has added since, such as
`SECOM TLS RSA Root CA 2024`, `SECOM TLS ECC Root CA 2024`, `Telia RSA TLS Root CA v3` and `Telia EC TLS Root CA v3`.

This bundle is the trust store for connectors that send HTTP requests and have no `cacertfile` configured. Set
`cacertfile` to pin the trust anchors of an outgoing connection yourself.
