GreptimeDB EMQX Tables actions now support writing `JSON2` columns from plain JSON binary fields. `JSON2` columns can be created automatically by declaring the corresponding field in `field_types`, for example `field_types = { payload = json2 }`; without that declaration, auto-created tables infer binary fields as `STRING`. GreptimeDB currently accepts only JSON objects or null for `JSON2`; arrays and scalar documents are rejected. See the [GreptimeDB JSON2 limitations](https://docs.greptime.cn/user-guide/logs/json2/#%E5%BD%93%E5%89%8D%E9%99%90%E5%88%B6). Invalid JSON or an unsupported document shape aborts the affected table's insert batch as an unrecoverable error, while other tables in the same action batch may still be written. EMQX Tables uses row inserts, not stream/bulk writes. This requires GreptimeDB v1.2.1 or newer.
