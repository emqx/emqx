GreptimeDB EMQX Tables actions now support writing JSON documents to pre-created `JSON2` columns. Set `field_types = { payload = json2 }` to automatically create a `JSON2` column when the target table does not exist. Known limitation: if the first message that auto-creates a table omits a declared `JSON2` field, a later message cannot add that field because the table is not append-only. Pre-create the table with `append_mode = 'true'` for sparse `JSON2` fields. This requires GreptimeDB v1.2.1 or newer.
