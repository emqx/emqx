Removed the RPC insecure authentication fallback.

Cluster nodes now always authenticate their backplane (RPC) connections with a challenge-response
handshake. The old fallback, which sent the Erlang cookie to the peer when the handshake failed,
has been removed.

The `rpc.insecure_fallback` config key no longer has any effect. It existed to cluster with EMQX
releases older than 5.3.0, which do not speak the challenge-response handshake. A config file that
still sets the key keeps loading, and the value is ignored.
