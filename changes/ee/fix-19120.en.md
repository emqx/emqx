Fixed `emqx ctl conf load --merge` and `PUT /api/v5/configs?mode=merge` so that they no longer reset omitted fields to their defaults. Before this fix, loading one field of a config struct reset every other field of that struct. For example, loading only `listeners.tcp.default.tcp_options.active_n` reset the listener's `parse_unit`, `bind`, `acceptors` and `max_connections`, and loading only `mqtt.max_packet_size` reset `mqtt.idle_timeout` and `mqtt.max_inflight`. Merge mode now keeps the stored values of omitted fields. A merge no longer needs to repeat the required fields of a struct that the stored configuration already holds, for example `bootstrap_hosts` of a connector or `type` of a schema registry entry. Merge mode also keeps the stored authorization sources when the loaded file does not contain `authorization.sources`. Replace mode is unchanged.
