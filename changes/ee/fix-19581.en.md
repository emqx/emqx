Fixed a rolling upgrade that could stop with client sessions left on an old node. Nodes that run 5.8 to 5.10, 6.0.0 to 6.0.3, 6.1.0 to 6.1.4, 6.2.0 to 6.2.3 or 6.3.0 move sessions to other nodes during node evacuation with a call that 6.0.4, 6.1.5 and 6.3.1 no longer answered. The old node then kept the sessions and tried again without end, so the evacuation did not complete. The new node answers this call again.
