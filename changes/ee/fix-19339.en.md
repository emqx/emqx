Fixed installing a plugin package that bundles an application which EMQX already provides.

Such a package was refused with `plugin_app_loaded_outside_package`, for example the `emqx_acme` plugin, which bundles `jose`. The package now installs when the bundled application has the same `.app` file as the one in EMQX, and the plugin uses the copy that EMQX has loaded. A package that bundles a different version of such an application is still refused.

Plugin packages built with `mix emqx.plugin` no longer bundle the dependencies that EMQX provides.
