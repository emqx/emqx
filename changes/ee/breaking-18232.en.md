Changed the default EMQX security profile from `legacy` to `hardened`. Default MQTT and Dashboard listeners now bind to loopback; authentication, authorization, and access-control failures fail closed; unchanged Dashboard default credentials are rejected; outbound TLS verifies peers; missing JWTs are rejected; SAML signatures are required; and internal subscriptions are authorized. Set `EMQX_SECURITY_PROFILE=legacy` to retain the previous behavior during migration.
