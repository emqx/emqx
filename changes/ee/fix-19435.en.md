When a REST API handler failed with an internal error, the HTTP 500 response and the warning log entry contained the arguments of the failed function. These arguments include the request headers and the request body. As a result, the value of the `authorization` header (a bearer token, or an API key and secret) and request body fields could be written to the log. The response and the log now keep only the structure of these values. Header names and body field names stay visible, and each string value is replaced by its length.
