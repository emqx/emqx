Fixed flapping detection settings that the deprecated flat fields (`enable`, `window_time`, `max_count`, `ban_time`) set in a higher-priority configuration source. When a lower-priority source, for example `cluster.hocon`, set `flapping_detect.by_clientid`, the flat fields in `emqx.conf` or in environment variables had no effect, and `enable = false` did not disable the detection. Each field now takes the value from the source with the highest priority, in either layout. The same fix applies to zone overrides and to `emqx ctl conf reload`.
