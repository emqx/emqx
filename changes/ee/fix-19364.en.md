Fixed installing a plugin package that bundles an application which EMQX already provides.

Such a package was refused with `plugin_app_loaded_outside_package`. The package now installs, and the plugin uses the copy of the application that EMQX has loaded, whatever version the package bundles. When the versions differ, EMQX logs a `plugin_app_already_loaded` warning. Stopping or uninstalling the plugin does not stop or unload the EMQX copy.
