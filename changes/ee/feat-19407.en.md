A QUIC connection now takes its hibernation timeout from `mqtt.hibernate_after` of the listener's zone, the same as a TCP or SSL connection. The control stream and the data streams of the connection both use this value.

The QUIC listener setting `listeners.quic.<name>.ssl_options.hibernate_after` is deprecated. EMQX still accepts it in the configuration, but it has no effect. Before this change, the QUIC listener setting was in use, and a change of `mqtt.hibernate_after` had no effect on QUIC connections.

Both settings default to `5s`. When neither setting was changed, the hibernation behavior of QUIC connections does not change.
